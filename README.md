# 光学探索 · Optics Explorer

面向光学检测初学者的交互式教学实验室。已实现时域 OCT、光谱域 SD-OCT 和单层薄膜椭偏三个实验，使用 React、TypeScript、Three.js 和 Vite，全部计算在浏览器中完成，无需后端。

## 运行

需要 Node.js 20.19+ 或 22.12+。

```powershell
npm install
npm run dev
```

打开终端给出的本地地址（默认 http://127.0.0.1:5173）。生产构建使用 `npm run build`，预览构建使用 `npm run preview`。`dist/` 可部署至支持静态网站的服务。

## 导航与布局

左侧可直接切换三个实验，浏览器前进 / 后退及刷新保留当前技术入口。切换技术时停止并释放当前动画和场景，进入目标技术的初始状态。支持直接链接：`/#td-oct`、`/#sd-oct`、`/#ellipsometry`。

所有实验沿用三栏满屏布局、器件说明、透视 / 俯视切换、恢复视角与三步教学指南。实验参数对话框支持 Esc 关闭和键盘焦点约束。

## 时域 OCT 操作

- 桌面优先，主要适配 1440×900 和 1366×768；三栏布局占满视口，无页面或面板纵向滚动。手机竖屏提示转为横屏，首版未提供独立手机实验界面。
- 拖动 3D 场景旋转，滚轮缩放；点击器件模型或名称查看说明，也可用键盘访问标签。工具栏提供俯视、透视、标签开关和恢复视角。
- 参考镜范围 0–200 μm；样品范围 −20–20 μm。样品正向为沿入射方向远离分束器；参考镜正向为远离分束器。
- 开始扫描后以 10、20 或 40 μm/s 向终点扫描，逐步绘制实际经过的区间；到终点自动停止。切换到其他标签页会暂停。
- 手动移动参考镜会暂停并保留旧记录，位置游标随之移动；重新从不连续的位置开始扫描会重新记录。移动样品会暂停并清空旧记录。
- 点击界面卡片可定位到预期峰位，不会伪造扫描数据；先查看当前光程差，再从该处扫描。全程 / 局部切换便于观察包络和载波。
- 重置恢复器件位置、扫描速度、默认视角、标签、教学步骤与图表，并清空记录。

## 时域 OCT 物理模型

所有内部长度单位均为 μm。采用近似高斯光谱，中心波长 λ₀ = 0.85 μm、光谱带宽 Δλ = 0.05 μm。固定样品折射率 n = 1.40，三个界面的样品内深度 zᵢ = 0、40、80 μm；等效反射场振幅 aᵢ = 1、0.70、0.48，已吸收固定透射与检测比例。

```text
δz_air = (2 ln 2 / π) λ₀² / Δλ ≈ 6.38 μm
δz_sample = δz_air / n ≈ 4.55 μm
xᵢ = 50 + s + n zᵢ
Δᵢ = 2(xᵣ − xᵢ)
gᵢ = aᵢ exp[−4 ln 2 (Δᵢ / (2δz_air))²]
I_AC = Σ gᵢ cos(2π Δᵢ / λ₀)
E = |Σ gᵢ exp(i 2π Δᵢ / λ₀)|
```

50 μm 是选定的光程基准偏置，非样品内部深度。零样品位移时，三峰对应参考镜位置 50、106、162 μm。图表横轴是镜面位移，卡片是样品深度；二者通过折射率和偏置换算。镜面位移 1 μm 对应 2 μm 往返光程变化。

图中“原始干涉信号”指去除直流背景后的参考臂与样品臂交叉干涉项，以相对幅度显示。包络直接由解析复场计算，未经过数值解调。忽略噪声、色散、多次反射、样品自相关和探测器带宽效应；这是教学模型，不是硬件仿真或医疗设备。

3D 光学器件与静态臂长为示意结构。两个位移控制均使用 0.012 场景单位 / μm 的显示增益；样品内界面间距也经放大。光路粒子只示意方向，不表示真实传播速度。数值模型独立于渲染比例。

原理参考：[CMU Interferometric Imaging](https://imaging.cs.cmu.edu/interferometry-iccp-course/)、[Thorlabs OCT Tutorial](https://www.thorlabs.com/catalogpages/Obsolete/2023/GAN311.pdf)。布局参考：[Protocol Explorer](https://protocol-explorer-alpha.vercel.app/)。

## 光谱域 SD-OCT

3D 系统显示宽带光源、分束器、固定参考镜、三界面样品以及打开上盖的光谱仪（光栅与线阵相机）。参考镜不扫描；所有界面同时编码在一帧光谱中。

- 同时显示含直流的原始光谱和 FFT 深度重建；支持全谱 / 条纹局部切换。
- 样品可平移 −20–20 μm；光源光谱带宽可调 20–80 nm。
- “采样设置”提供 512 / 1024 / 2048 像素和 Hann 窗。更多像素扩大无混叠深度范围，加窗抑制旁瓣但展宽主峰。
- 初始实时采集；暂停后冻结上一帧。此时调整参数会保留旧曲线并提示待更新，继续采集后才应用新参数。
- 卡片显示从 FFT 峰换算的样品内深度，点击可选中对应 3D 界面。

光谱仪在 750–950 nm 范围等波长采样，高斯光谱中心 850 nm。采用弱样品场系数 ε = 0.07、相对界面振幅 1 / 0.70 / 0.48：

```text
xᵢ = 50 + s + n zᵢ
k = 2π / λ
B = 1 + ε² Σ aᵢ²
I(λ) = S(λ) [B + 2ε Σ aᵢ cos(2 k xᵢ)]
等波长采样 → 线性插值至等 k → 减已知背景 → 可选 Hann 窗 → FFT
xⱼ = πj / (M δk)
Aⱼ = 2 |FFTⱼ| / Σ(S w)
z_sample = (x_peak − 50 − s) / 1.4
```

实现使用数值 radix-2 FFT，四倍补零，并对峰顶做局部对数抛物线插值；重建过程不注入标称峰位。图上标记是理论预期位置，卡片来自数值峰检测。补零和峰顶插值细化坐标，不提高物理分辨率。

忽略弱样品自相关、噪声、色散和光谱仪灵敏度衰减；采用已知背景，不模拟真实背景标定。显示的是正深度半轴，未实现消除共轭镜像的全范围复 OCT。图的横轴为**等效空气深度**，不能直接当成样品内深度。

参考：[OCT: Principle and Technical Realization](https://www.ncbi.nlm.nih.gov/books/NBK554044/)。

## 单层薄膜椭偏

3D 光路为单色光源 → 固定 45° 起偏器 → 空气 / 薄膜 / 基底 → 旋转线性检偏器 → 光电探测器。入射角以表面法线为基准；调整角度时两条光臂及法线角度标记同步变化。薄膜厚度和偏振波形采用放大示意。

- 膜厚 0–500 nm（0 表示裸基底），入射角 45–80°，检偏器角度 0–180°。
- 同时显示 Ψ、Δ、检偏器前的归一化反射偏振椭圆、检偏强度曲线和当前角度游标。
- 自动旋转速度为 30°/s，可暂停；手动改变检偏器角度会暂停自动旋转。切到其他标签页或其他技术也会停止旋转。
- 改变膜厚和入射角会改变 Ψ、Δ；转动检偏器只改变探测强度，不改变其前方的反射偏振状态。

固定 λ = 632.8 nm，n₀ = 1、n₁ = 1.46、n₂ = 3.88，均为无吸收教学常数，不是特定实际材料的精确光学常数。均匀各向同性单层膜覆盖半无限基底，使用 Snell 定律和 Fresnel 系数，含膜内多次反射：

```text
β = 2π n₁ d cosθ₁ / λ
rⱼ = (r₀₁,ⱼ + r₁₂,ⱼ exp(2iβ)) / (1 + r₀₁,ⱼ r₁₂,ⱼ exp(2iβ))
ρ = rₚ / rₛ = tanΨ exp(iΔ)
I(A) / I₀ = |rₚ cosA + rₛ sinA|² / 2
```

采用 exp(−iωt) 约定，Δ 映射至 [0°, 360°)。I₀ 是起偏器后的入射光强。显示的 Ψ、Δ 由模型计算；旋转线性检偏器曲线只含 cosΔ，单独使用不能区分 Δ 与 360°−Δ。未加入补偿器，不进行完整相位测量或膜厚反演。单波长响应对膜厚存在周期性多解。

参考：[Scott Prahl: Ellipsometer Basics](https://pypolar.readthedocs.io/en/latest/10a-Ellipsometry.html)。


## 文件

- `src/physics.ts`：物理模型与扫描状态转换。
- `src/OpticalScene.tsx`：3D 器件、光路、选取、标签与视角。
- `src/SignalPlot.tsx`：高分辨率 Canvas 信号曲线与包络。
- `src/App.tsx` / `src/LabShell.tsx`：技术入口、浏览器历史及共享布局。
- `src/TimeDomainLab.tsx`：时域 OCT 实验。
- `src/SpectralLab.tsx` / `src/spectralPhysics.ts`：SD-OCT 界面、光谱采样与 FFT。
- `src/EllipsometryLab.tsx` / `src/ellipsometryPhysics.ts` / `src/EllipsometryScene.tsx`：椭偏界面、薄膜模型及 3D 光路。
- `src/LabUI.tsx` / `src/ScientificPlot.tsx`：共享教学组件、对话框和科学曲线。
- `src/styles.css`：布局、配色和尺寸适配。
- `src/modules.css`：新增实验的图表、参数和布局样式。

不依赖外部 3D 模型、远程图片、API 或账号。字体优先 DM Sans（Google Fonts，网络不可用时自动使用系统字体）；所有实验功能可在本地离线运行。
