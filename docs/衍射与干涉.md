# 衍射与干涉

**衍射**（Diffraction），又称**绕射**，是指波遇到障碍物时偏离原来直线传播的物理现象。是波的固有特性。

干涉是有限个波相互作用，衍射是无限个波相互作用，因此两者是同一种东西，没有什么特别的重要的区别。

## 菲涅尔衍射与夫琅和费衍射

最直观的区别就是一个近一个远，近的是菲涅尔衍射，远的是夫琅和费衍射。

> 这里的远近指的是衍射屏到观察屏的距离

单单说明远近来判断菲涅尔衍射以及夫琅和费衍射是不严谨的，引用工程光学中的原话：

> *产生夫琅和费衍射对距离的要求要比菲涅尔衍射苛刻的多，显然菲涅尔衍射区包含了夫琅和费衍射区。凡是能用来计算菲尼尔衍射的公式都适用于夫琅和费衍射，反之则不然*
